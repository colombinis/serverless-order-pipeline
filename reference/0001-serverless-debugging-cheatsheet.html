Las dos sintaxis de referencias

  • ${self:service}, ${self:provider.stage} — interpolación de Serverless, resuelta por el CLI local
  • !Ref OrderQueue, !GetAtt OrdersTable.Arn — funciones intrínsecas de CloudFormation, resueltas al desplegar
  • ${opt:stage, 'dev'} — variable de CLI con default: --stage prod la sobreescribe

Las 3 capas de debugging

Capa 1 — Contenedores

docker compose ps                        # estado de cada contenedor
docker compose logs -f app               # logs de serverless + Lambdas emuladas
docker compose logs -f ministack         # logs del emulador
docker logs serverless-order-pipeline-app 2>&1 | grep -A5 ERROR

Capa 2 — CloudWatch Logs (emulado)

sls logs -f createOrder -t               # tail de logs del handler, contra emulador
sls logs -f createOrder                  # últimos logs sin seguimiento

Capa 3 — Estado de los recursos (CLI contra :4566)

EP=http://localhost:4566
aws --endpoint-url $EP dynamodb list-tables
aws --endpoint-url $EP sqs list-queues
aws --endpoint-url $EP sns list-topics
aws --endpoint-url $EP stepfunctions list-state-machines
aws --endpoint-url $EP lambda list-functions
aws --endpoint-url $EP cloudformation list-stacks --query 'StackSummaries[?StackStatus==`UPDATE_COMPLETE`].StackName'
curl http://localhost:4566/health       # salud del emulador (63+ servicios)
curl http://localhost:4566/_ministack/health

MiniStack — datos clave

  • Un solo puerto 4566 para todos los servicios; se enruta por scope de auth / X-Amz-Target / path
  • No valida credenciales: cualquier access key funciona; la key de 12 dígitos se vuelve el account id
  • Sin PERSIST_STATE=1, todo es efímero: reiniciás el contenedor y quedó con un estado limpio
  • JSON API multi-account / multi-región: la región del scope SigV4 aísla recursos
  • Health: curl http://localhost:4566/health (aliases de LocalStack funcionan: /_localstack/health)

Comandos útiles del proyecto

npm run offline          # serverless offline start  (puerto 3000)
npm run bootstrap:ministack  # crea tabla/cola/tópico/SFN + 8 Lambdas + ESM SQS→processOrder en MiniStack (idempotente, smoke test)
npm run deploy           # serverless deploy   (stage dev, EN TIEMPO REAL si no apuntás al emulador)
npm run deploy:local     # serverless deploy contra MiniStack (shim SDK v2 → AWS_ENDPOINT_URL); llegarás al muro del CF del emulador
npm run deploy:prod      # serverless deploy --stage prod
# deploy:local usa el env del entorno. En el contenedor ya está MiniStack; en el host:
#   AWS_ENDPOINT_URL=http://localhost:4566 npm run deploy:local
npm test                 # Jest con mocks del SDK (sin AWS)
npm run lint             # eslint src tests
