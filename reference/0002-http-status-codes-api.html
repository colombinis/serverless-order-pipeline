Cómo elegir un código de éxito (2xx)

CódigoAfirmaRequisito / usoEn este proyecto
200 OKLa petición funcionó.Respuesta genérica con cuerpo. El default de un GET.Consultar/leer una orden.
201 CreatedSe creó un recurso.Idealmente con Location apuntando al recurso nuevo. Típico de POST.POST /orders → createOrder (crea la fila PENDING y devuelve orderId).
202 AcceptedSe aceptó para procesar; no terminó.Non-committal: no hay forma de devolver el resultado luego. Trabajo en otro proceso o por lotes.Sería el caso si API Gateway invocara la Lambda async (sin cuerpo).
204 No ContentFue bien y no hay cuerpo.Éxito sin representación. Típico de DELETE / PUT sin retorno.Un DELETE /orders/{id} futuro.

Regla de bolsillo

¿Existe un recurso nuevo que puedo señalar? → 201.  ¿Solo encolé trabajo y todavía no hay recurso? → 202.  ¿Funcionó y no devuelvo nada? → 204.

Códigos de error frecuentes en este pipeline

CódigoSignificaDónde aparece aquí
400Bad Request — datos inválidos.createOrder si falta customerId o items está vacío.
404Not Found — el recurso no existe.Consulta de una orden con orderId inexistente.
409Conflict — choque de estado.Recrear una orden con un id duplicado (idempotencia).
429Too Many Requests — throttling.API Gateway o Lambda bajo ráfaga (TooManyRequestsException).
500Internal Server Error — fallo del backend.Error no capturado en un handler.
502Bad Gateway — respuesta inválida de un upstream.Una Lambda devuelve un return mal formado que API Gateway no puede interpretar.
504Gateway Timeout — el upstream no respondió a tiempo.La Lambda excede el timeout de integración de API Gateway (29 s).

Fuente: AWS Lambda — Invoke API. Para configurar la invocación async en API Gateway: header X-Amz-Invocation-Type: Event (guía oficial).

Definiciones canónicas (RFC 9110)

  • 201 Created — «the HTTP request has led to the creation of a resource»; el recurso existe antes de responder.
  • 202 Accepted — «non-committal»; la petición se aceptó para procesar, sin garantía de resultado.
  • Resumen didáctico: MDN 201 y MDN 202.
