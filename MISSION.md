# Mission: AWS Services Deep Dive for Certification

## Why
Estoy estudiando para la certificación AWS y quiero dominar cada servicio que usa este proyecto en profundidad — no solo qué hacen, sino cómo se conectan, por qué se diseñaron así, y los fallos más comunes en producción y en exámenes.

## Success looks like
- Puedo explicar cada servicio del proyecto (Lambda, API Gateway, DynamoDB, SQS, SNS, Step Functions, IAM, CloudFormation, CloudWatch) con sus conceptos clave, límites, y casos de uso
- Reconozco los patrones de arquitectura serverless y por qué este proyecto los usa
- Identifico los fallos más comunes (cold starts, throttling, idempotencia, DLQ, permissions, etc.) y sé cómo prevenirlos
- Puedo resolver preguntas de certificación que involucren estos servicios

## Constraints
- El proyecto es el foco: cada lección se ancla en código real del repo
- Profundidad sobre amplitud: mejor entender Lambda a fondo que superficialmente
- Las lecciones deben ser cortas y completables rápido

## Out of scope
- Servicios AWS que no aparecen en este proyecto (EC2, ECS, RDS, etc.)
- Migración del proyecto a otros servicios
- Configuración avanzada de Serverless Framework más allá de lo necesario para entender la infraestructura
